# Screenshot Placeholders

To capture authentic screenshots of Mesh-Pulse:

1. Launch isolated demo mode in a standard 80x24+ terminal:
   ```bash
   mesh-pulse --demo
   ```
2. Recommended screenshot captures:
   - `dashboard.png`: Main dashboard screen showing connected peers, system health, and transfer widgets.
   - `peer_workspace.png`: Selected peer detail view (`Enter` on a peer) showing latency and transfer stats.
   - `inbox.png`: Incoming transfer approval modal (`i`).
   - `history.png`: Global SQLite transfer history screen (`h`).
